# Enterprise-Network-Infrastructure-Security-Lab
Designed and implemented an enterprise-style network environment covering routing, switching, connectivity, security, and high availability.
Tool: GNS3, PuTTY, VirtualBox
- Configured VLANs, VTP, inter-VLAN routing, and DHCP to support segmented office networks and automated IP allocation.
- Implemented OSPF and WAN connectivity and configured NAT and ACL policies to manage network access and internal-to-external connectivity.
- Implemented HSRP/VRRP for default-gateway redundancy and configured public IP mapping for an internal web server.
- Performed connectivity testing and troubleshooting using network diagnostic and packet-analysis tools.

.gns3project file is a exported portable project, which can be opened directly using GNS3 application.

.pdf file is a report, which summarize achieved knowledge and the process of doing this project
